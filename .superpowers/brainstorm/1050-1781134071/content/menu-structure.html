How should the collapsed menu work?

Tab bar keeps: Overview · Team Radar · Leading Behaviours · Trends · (Exec Brief, admins only). The question is what the collapsed panel contains and where it sits. Wireframes show an admin's view with the menu open.

A

Top-left hamburger — secondary pages only

☰ button left of the logo. The panel lists only the pages that left the tab bar: Data Reference (everyone), Scoring Weights + Access Control (admins). Primary tabs stay where they are — no duplication.

B

Top-left hamburger — full navigation drawer

☰ opens a drawer listing everything: the 4 primary tabs plus the secondary pages, grouped with a divider. One place to navigate anywhere (handy on mobile), but duplicates the tab bar.

No hamburger. The tab bar ends with a ⋯ More button that drops down the secondary pages. Keeps all navigation in one row, but is less of the "modern website" top-left pattern you described.
