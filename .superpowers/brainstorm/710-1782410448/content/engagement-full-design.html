Design decisions baked in

  • Pace threshold: floor(weeksElapsed / 2) — week 12 → need ≥6 self-comments. 8 goals / 6 comments = passes.
  • Silent tier: 0 self-comments, highest priority, dark red background in list
  • Below Pace tier: >0 but below threshold, amber background
  • At Pace: shown in table for completeness but no HR Review button
  • Manager identification: job title regex for VP / Director / C-suite / CEO → Senior Leader badge, included in scorecard
  • Manager scorecard colour: green ≥2 avg cmts, amber 1–2, red <1
  • Team engagement colour: green ≥75%, amber 50–74%, red <50%
  • Tab rename: "Comments Trend" → "Engagement" in the tab nav
  • Backend: new computeEngagementData_() function added to the return payload; cache bumped to gd_v4_
