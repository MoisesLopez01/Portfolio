Where should the Goals Audit live?

Three options for surfacing inactivity flags and compliance status

A

New section in Trends tab

Below the existing Goals Standing card, add an "Activity Audit" panel — a table of flagged rocketeers with columns: Name · Goals · Status · Self-comments (Q4) · Last activity date · Flag reason. Stays in context with the trends data.

B

Inline flags in the employee roster table

Each rocketeer row in the existing team table gets an audit badge: 🟡 0 activity or ✅ Compliant (all done). Managers see it directly on the roster without switching context. No new UI section needed.

C

Both: Audit section in Trends + badges on roster

Trends tab gets a dedicated audit section (team-wide view, exportable), and the roster table gets per-row badges. Managers can scan the roster daily; the Trends audit gives a focused action list for weekly reviews.
